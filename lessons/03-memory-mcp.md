# Lesson 03 — Memory MCP 实战

- 状态:已完成
- 记录日期:2026-10-13
- 涉及工具:Memory MCP(知识图谱式长期记忆)

## 学习目标

- 理解 Memory MCP 的三个核心概念:实体(Entity)、关系(Relation)、观察(Observation)
- 掌握让 AI 跨会话记住用户偏好与项目上下文的方法

## 实战过程

1. 创建实体:把「用户」「项目」等抽象为知识图谱中的节点
2. 建立关系:用关系边描述实体间的连接(如 用户 —使用→ 某技术栈)
3. 添加观察:以事实条目形式向实体追加信息(偏好、约束、已做的决定)
4. 检索记忆:通过 search_nodes / open_nodes / read_graph 读取并核对已有记忆

## 产出成果

- 用户画像记忆:沟通语言、输出格式等跨项目偏好
- 项目级记忆:本仓库相关的约定与历史决定

## 关键收获

- 工作方式从「每次对话重新粘贴背景」转变为「AI 主动携带长期上下文」
- 记忆要分层:跨项目通用的偏好写入用户级,仅与当前仓库相关的约定写入项目级
- 记忆是增量演化的:定期回顾、修正过时条目,比一次性写入更重要

## 问题与解决

- 问题:不确定某条信息该记入用户级还是项目级
  - 原因:两层记忆的作用范围不同,归属判断标准不清晰
  - 解决:以「换一个项目是否仍然成立」为判断标准,成立则记入用户级
