# Lesson 04 — project-weekly-report Skill 实战

- 状态:已完成
- 记录日期:2026-10-13
- 涉及工具:Trae Skill(project-weekly-report)

## 学习目标

- 理解 Skill 的定位:把一类任务的流程、格式与质量标准封装成可复用能力
- 掌握以自然语言意图触发 Skill,生成银行内部项目周报

## 实战过程

1. 准备输入:项目试点数据、阶段性进展记录、会议纪要要点
2. 以自然语言提出「生成项目周报」,由意图匹配触发 project-weekly-report Skill
3. 检查生成结果的结构、口径与数据引用,补充缺失数据后迭代重新生成

## 产出成果

- 一份结构完整的项目周报(进展、数据、风险、下周计划)

## 关键收获

- Skill 与单次提示词的区别:Skill 固化的是「流程 + 模板 + 质量标准」,而不只是一段 prompt
- 输入越结构化,产出越稳定;对缺失数据应显式说明,让 Skill 留空而不是推测
- 适合封装为 Skill 的任务特征:高频重复、格式固定、质量要求明确

## 问题与解决

- 问题:首次生成时部分内容缺少数据来源
  - 原因:输入材料中未给出该部分的数据口径
  - 解决:在输入中显式列出本周数据口径与缺失项,重新生成
