## 编号说明

课次编号沿用训练营课程编号,因此从 02 开始;01 为导学与环境准备,未单独记录。

## 状态约定

- **未开始**:已排入计划,尚未动手
- **进行中**:已开始实战,记录尚未完整
- **已完成**:实战与记录均完成

## 记录规范

- 新课时复制 [../templates/lesson-template.md](../templates/lesson-template.md) 作为起点
- 文件命名:`课次编号-短横线主题.md`,如 `03-memory-mcp.md`
- 每完成一课,同步更新本表与根 README 的进度总览,保证两处一致

## 工作流

所有变更走「新分支 → commit → Pull Request → review → 合入 main」,不直接提交到 main。
