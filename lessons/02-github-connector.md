# Lesson 02 — GitHub Connector Practice

This file was created directly through the GitHub connector as part of the AI training camp.

## What this exercise demonstrates

- Read a repository without copy-pasting code into chat
- Create a branch
- Create a file and commit it
- Open a pull request for review

## Key idea

The useful shift is from:

`copy code → ask AI → manually edit GitHub`

to:

`give AI a goal → AI reads repo → AI makes a branch → AI changes files → AI opens a PR`

## Safety rule

For real projects, prefer making changes on a branch and reviewing the pull request before merging.
